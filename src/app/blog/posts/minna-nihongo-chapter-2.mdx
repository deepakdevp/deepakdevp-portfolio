## The Challenge: Japanese Has Three "This/That" Forms

English is simple:
- **This** (near me)
- **That** (away from me)

Japanese has three levels of distance:
- **これ (kore)** - this (near me)
- **それ (sore)** - that (near you)
- **あれ (are)** - that over there (far from both of us)

This took me a week to internalize. Let me show you why.

## これ/それ/あれ (Kore/Sore/Are)

These point to **things**.

### これ (kore) - This (near me)

```
これは本です。
(Kore wa hon desu)
This is a book.
```

Use これ when the object is **close to you**.

### それ (sore) - That (near you)

```
それは何ですか。
(Sore wa nan desu ka)
What is that?
```

Use それ when the object is **close to the listener**, not you.

### あれ (are) - That over there (far from both)

```
あれは私の車です。
(Are wa watashi no kuruma desu)
That over there is my car.
```

Use あれ when the object is **far from both** of you.

## Practicing with Claude Code

I struggled with この system until Claude Code made me do this exercise:

**Scenario:** You're in an office. Three laptops:
1. On your desk (これ)
2. On your colleague's desk next to you (それ)
3. Across the room on someone else's desk (あれ)

```
これは私のラップトップです。
(This is my laptop - on my desk)

それは田中さんのラップトップですか。
(Is that Tanaka-san's laptop? - on their desk next to you)

あれは誰のラップトップですか。
(Whose laptop is that over there? - across the room)
```

**This clicked.** It's not about absolute distance—it's about **proximity to speaker vs listener**.

My wife added another tip: "If you're on the phone, everything is あれ because nothing is close to either of you physically!"

## この/その/あの + Noun

これ/それ/あれ work alone as pronouns. But you often want to say "**this book**" or "**that pen**."

For that, you use:
- **この** (kono) + noun - this [noun]
- **その** (sono) + noun - that [noun]
- **あの** (ano) + noun - that [noun] over there

Examples:
- この本 (kono hon) - this book
- その鉛筆 (sono enpitsu) - that pencil
- あのビル (ano biru) - that building over there

**Key difference:**
- これ**は**本です (This **is** a book) ← これ stands alone
- この本**は**新しいです (This book **is** new) ← この modifies 本

Claude Code drilled this with workplace examples:

```
このペンは私のです。
(This pen is mine)

その資料は何ですか。
(What is that document?)

あの会議室は空いていますか。
(Is that conference room over there available?)
```

## Location Words: ここ/そこ/あそこ

Same three-way distance system, but for **places**:

- **ここ** (koko) - here (near me)
- **そこ** (soko) - there (near you)
- **あそこ** (asoko) - over there (far from both)

Examples:
```
ここは受付です。
(Here is the reception)

そこは何ですか。
(What is there? / What is that place?)

トイレはあそこです。
(The bathroom is over there)
```

## The Magic Question: どれ/どの/どこ

To ask "which?" or "where?", use:
- **どれ** (dore) - which one?
- **どの** + noun (dono) - which [noun]?
- **どこ** (doko) - where?

```
A: あなたのカバンはどれですか。
   (Which one is your bag?)

B: これです。
   (This one)
```

```
A: どのペンが好きですか。
   (Which pen do you like?)

B: このペンが好きです。
   (I like this pen)
```

```
A: 会議室はどこですか。
   (Where is the conference room?)

B: あそこです。
   (Over there)
```

## Vocabulary: Workplace Objects

Chapter 2 has basic vocab (book, pen, desk), but I wanted **office-specific words**. Claude Code helped me build a custom vocab list:

**Office items:**
- ラップトップ (rapputoppu) - laptop
- スマホ / 携帯 (sumaho / keitai) - smartphone / mobile phone
- 資料 (shiryō) - documents/materials
- ファイル (fairu) - file
- USBメモリー (USB memorī) - USB drive

**Locations:**
- 会議室 (kaigishitsu) - conference room
- 休憩室 (kyūkeishitsu) - break room
- トイレ (toire) - bathroom
- 受付 (uketsuke) - reception
- エレベーター (erebētā) - elevator

**Sample office conversation:**
```
A: すみません、会議室はどこですか。
   (Excuse me, where is the conference room?)

B: あそこです。エレベーターの隣です。
   (Over there. Next to the elevator)

A: ありがとうございます。この資料は会議室のですか。
   (Thank you. Is this document for the conference room?)

B: はい、そうです。
   (Yes, that's right)
```

## Possessive Questions: 誰の (Dare no)

To ask "whose?", use **誰の** (dare no).

```
これは誰の鞄ですか。
(Kore wa dare no kaban desu ka)
Whose bag is this?

→ 私のです。(Watashi no desu) - It's mine
→ 田中さんのです。(Tanaka-san no desu) - It's Tanaka-san's
```

Note the shorthand: **私のです** instead of 私の鞄です. The noun is implied.

Claude Code created this drill:

```
Q: このラップトップは誰のですか。
A: 私のです。

Q: そのペンは誰のですか。
A: 田中さんのです。

Q: あの車は誰のですか。
A: 分かりません。(I don't know)
```

## Common Mistakes I Made

### Mistake 1: Using これ for everything

❌ これは田中さんのペンです。(when the pen is near Tanaka-san, not me)
✅ それは田中さんのペンです。

**Fix:** Think about proximity to **speaker vs listener**, not just "near vs far."

### Mistake 2: Mixing この vs これ

❌ この は本です。(この can't stand alone)
✅ これは本です。(これ alone as pronoun)
✅ この本は新しいです。(この modifies noun)

**Fix:** この/その/あの **always** go before a noun. これ/それ/あれ stand alone.

### Mistake 3: Forgetting particles

❌ これ私のです。(missing は)
✅ これは私のです。

**Fix:** Always use **は** after これ/それ/あれ when making a statement.

Claude Code caught these mistakes instantly during practice, which saved me from cementing bad habits.

## Real-World Application

After learning Chapter 2, I tested it at a Japanese restaurant in my city.

**Scenario:** Ordering with a Japanese server

```
Server: こちらはメニューです。
        (This is the menu)

Me: ありがとうございます。これは何ですか。
    (Thank you. What is this?) [pointing to a menu item]

Server: それはラーメンです。
        (That is ramen)

    (Then, I'll have that)
```

**It worked!** The server smiled and seemed pleased I was trying Japanese.
