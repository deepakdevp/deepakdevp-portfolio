## Overview

**MBARC (MB Asset Management, Recycle & Care)** is an on-demand B2B marketplace for medical equipment services built at Medikabazaar. The platform connects healthcare facilities with 500+ certified service engineers for equipment maintenance, repairs, and lifecycle management.

As a **Full Stack Developer**, I architected and built core modules of this platform including the service booking system, engineer assignment workflows, asset tracking, and mobile applications.

## My Contributions

### 🏗️ Platform Architecture
- Designed the multi-tenant architecture supporting hospitals, clinics, and service engineers
- Built RESTful APIs handling 1000+ daily service requests
- Implemented real-time status tracking using WebSockets
- Set up CI/CD pipelines with Jenkins and Docker for automated deployments

### 📱 Mobile Applications
- Led development of React Native mobile apps for both iOS and Android
- Built offline-first architecture for engineers working in low-connectivity areas
- Implemented push notifications for service updates and assignments
- Integrated camera functionality for equipment documentation and reports

### 💼 Asset Management Module
- Created comprehensive asset lifecycle tracking system
- Built QR code scanning for quick equipment identification
- Implemented maintenance scheduling with automated reminders
- Developed reporting dashboards for hospital administrators

### 🔧 Service Booking System
- Built dynamic service request workflow with multi-stage approvals
- Implemented intelligent engineer assignment based on location, skills, and availability
- Created real-time tracking for service visits with ETA updates
- Built invoice generation and payment integration

## Key Features

### Asset Management
- Complete lifecycle tracking from procurement to disposal
- Automated maintenance schedules and compliance tracking
- Real-time asset health monitoring and alerts
- Comprehensive audit trails for regulatory compliance

### Service Marketplace
- On-demand booking for 6 service categories: Adhoc, Preventive, Breakdown, Installation, Calibration, and Training
- Support for 50+ equipment types including CT Scans, C-ARM, ECG, Defibrillators
- AMC/CMC (Annual/Comprehensive Maintenance Contracts) management
- Service history and equipment documentation

### Recycle & Refurbish
- Marketplace for buying/selling refurbished medical equipment
- Quality certification and grading system
- Secure transaction handling with escrow
- Logistics integration for equipment transport

## Challenges Solved

### 1. Complex Booking Workflows
Medical equipment servicing involves multiple approval stages, documentation requirements, and compliance checks. I designed a flexible workflow engine that adapts to different service types and hospital policies.

### 2. Offline-First Mobile Experience
Service engineers often work in areas with poor connectivity. Implemented local-first architecture with intelligent sync that queues actions offline and reconciles when connection is restored.

### 3. Real-Time Engineer Assignment
Built an intelligent assignment system considering engineer skills, location, current workload, and customer preferences to optimize service delivery times.

### 4. Multi-Tenant Data Isolation
Hospitals require strict data isolation for compliance. Implemented row-level security in PostgreSQL with organization-based access controls.
