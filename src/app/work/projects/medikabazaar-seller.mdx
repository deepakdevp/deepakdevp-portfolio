## Overview

**Medikabazaar Seller Platform** is India's largest B2B healthcare marketplace, connecting medical equipment suppliers with 250K+ verified healthcare customers across PAN India. I led the development of the fintech modules that power the platform's payment and invoicing infrastructure.

## My Contributions

### 💰 Fintech Modules (Team Lead)

Led a team of 5 engineers building the complete financial backbone:

**Accounts Receivable (AR)**
- Built automated invoice generation and tracking system
- Implemented payment reconciliation with multiple payment gateways
- Created credit note and refund management workflows
- Delivered real-time revenue dashboards for finance teams

**Accounts Payable (AP)**
- Developed supplier payout automation with 7-day payment guarantee
- Built multi-currency support for international suppliers
- Implemented approval workflows for large transactions
- Created vendor statement generation and dispute resolution

**Credit Workflows**
- Designed credit limit management for B2B buyers
- Built credit scoring integration for risk assessment
- Implemented buy-now-pay-later options for verified customers
- Created automated collection and reminder systems

### 📊 Automated Invoice Processing
- Built OCR-based invoice processing using **OpenAI Vision models**
- Automated extraction of line items, quantities, and amounts
- Reduced manual data entry by **80%**
- Implemented validation rules for invoice accuracy

### 🏗️ Platform Architecture
- Designed microservices architecture for fintech modules
- Built event-driven systems using **Kafka** for payment events
- Implemented CQRS pattern for financial reporting
- Set up **New Relic** monitoring for transaction tracking

### 🔐 Compliance & Security
- Implemented GST compliance for all transactions
- Built audit trails for financial operations
- Ensured PCI-DSS compliance for payment handling
- Created role-based access control for finance operations

## Challenges Solved

### 1. Complex B2B Payment Workflows
Unlike B2C, B2B payments involve credit terms, partial payments, and complex reconciliation. Built a flexible payment engine supporting multiple payment modes and credit structures.

### 2. GST Compliance at Scale
Every transaction needs GST-compliant invoicing. Automated GST calculation, e-way bill generation, and return filing integration.

### 3. Multi-Stakeholder Approval Flows
Large orders require multiple approvals. Designed configurable approval matrices based on order value, customer tier, and product category.

### 4. Invoice Processing at Scale
Thousands of supplier invoices daily. Built AI-powered OCR system that extracts data with 95%+ accuracy, reducing processing time from hours to seconds.
